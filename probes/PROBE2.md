Probe 2: can a small VLM run in a browser on WebGPU and answer "does an overlay/banner/modal cover the page?" fast enough?

Build probes/p2/ : index.html + main.js (ES modules from a CDN: @huggingface/transformers v3 latest). Use model onnx-community/SmolVLM-256M-Instruct (fallback HuggingFaceTB/SmolVLM-256M-Instruct ONNX, or onnx-community/Florence-2-base-ft), device "webgpu", dtype q4 or fp16 per model card. Page loads an image list from ./frames.json (array of URLs) and, for each image, asks: "Is there a cookie banner, popup, modal or overlay covering part of this web page? Answer yes or no." Parse yes/no. Record per image: answer raw, flagged bool|null, ms. Show results and also write them to window.__ghost = {ready, results, model, adapterInfo, loadMs}.
Serve with `bunx serve probes/p2 -l 4377` (background). Put 3 test images: copy probes/p1/frame0.jpg plus any jpgs in .real/frames/ (if present, up to 5).
Drive it ONLY with the cmux browser CLI: `cmux browser open http://localhost:4377` to get a new surface (note the surface ref it prints), then poll `cmux browser --surface <ref> eval 'JSON.stringify(window.__ghost)'` until ready or 6 minutes pass. cmux surfaces are WKWebView; if navigator.gpu is missing report that verbatim, then try device "wasm" as a fallback and record both.
Save probes/p2/result.json and a 10-line probes/p2/VERDICT.md (load ms, per-frame p50 ms, WebGPU available?, answers sane?). Close the surface you opened with `cmux close-surface --surface <ref>` when done. No source comments. No mocks.
