# L2 receipt: gym and real-site collection

## Collector
`gym/collector/` (Worker `ghost-gym-collector`, account 29db7c74093386544fed8046ef083a4b, browser binding, gated by `x-probe-key`, secret `PROBE_KEY`). POST `{url, target?}` returns `{url, ok, error?, label, observation, outcome, jpegBase64, ms}`.
- Gym pages (`target` selector given): wait for `__ghostReady`, +200 ms, screenshot (jpeg q70), observation facts, `__ghostAct()`, wait 300 ms, trusted click at the screenshot-time centre with a capture listener, then outcome facts (listener fired, actual event target, box at click time).
- Real sites (no `target`): load + 4 s, target by `eval/TARGET_RULE.md`, same screenshot, facts and click.
- workers.dev gave error 1050, so it was deployed on the custom domain `ghost-gym-collector.customer0.dev`. The local resolver never resolved that name, so the clients pinned the Cloudflare IP with SNI (`COLLECTOR_IP`).
- Worker deleted with `wrangler delete --force`, which removes the custom domain.
