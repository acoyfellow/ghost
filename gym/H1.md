# H1: on real sites, what remains is label noise

Pre-registered. This file is frozen before any page is collected for H1.

## Hypothesis

The guarded click is: just before the click, block when the click point is outside the viewport, or the target or one of its ancestors is disabled or inert, or `elementFromPoint` at the planned click point does not reach the target. On real sites its remaining error comes from pages that do not behave the same twice, not from a failure mechanism it cannot see.

## Data

- The 193 real holdout pages from `eval/frames.index.json` with `splitOf` = holdout.
- 3 new passes with the round 3 collector (`gym/collector`, the same code as test 1), into `.real/h1-p1`, `.real/h1-p2`, `.real/h1-p3`.
- The passes run one after another, not in parallel. The test 1 data is not used.
- A page counts if it loaded in all 3 passes.

## Systems, all defined before data

- `guard`: as above, from the `recheck` observation and `recheckPlannedHit`. No model, no compile.
- `dom-recheck`: `hitIsTarget !== true` on `recheck`.
- `rule-recheck-planned`: the frozen Fable rule (`a38d89d3`) on `recheck`, with `hitIsTarget` from `recheckPlannedHit`.

## Measures

- **Label disagreement D:** the fraction of page pairs, over the 3 pass pairs, where the labels differ.
- **Stable pages:** pages with the same label in all 3 passes.
- **Guard error on stable pages E_s:** the fraction of (stable page, pass) decisions where `guard` disagrees with the label.
- **Guard error on all pages E:** the same over all counted pages.
- A 95% bootstrap interval over pages, 2000 resamples, seed 1, for E_s and for E minus D.

## Predictions

1. **Primary.** E_s is at most 0.02. If H1 holds, the guard is right on the pages that behave the same each time.
2. E is at most D + 0.02.
3. Reported only: `guard` F1 against `dom-recheck` and `rule-recheck-planned` per pass.

## Verdict

- **Supported** if predictions 1 and 2 hold.
- **Falsified** otherwise. Then every stable page the guard gets wrong is listed by domain, with the hit element and the outcome. Those pages are the unseen mechanism to look for next.

## Known weaknesses, written before data

- One egress location and one browser. Pages that differ by country or by bot checks will look unstable, which raises D.
- A page that blocks the click the same way every time, for a reason in no observation fact, is the case H1 says is rare. 193 pages cannot detect a rate below about 1%.
